# Modified Binary Search

## Pattern description
Adapt the binary search bounds to rotated arrays, bitonic arrays, or non-obvious ordered spaces. The invariant is the key idea.

## Use cases
Use it for rotated arrays and search-space optimization.

## Example problem
Find the minimum value in a rotated sorted array

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
