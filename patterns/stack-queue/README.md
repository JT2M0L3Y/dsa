# Stack / Queue Patterns

## Pattern description
Use stacks for LIFO operations and queues for FIFO operations. Both are central to parsing, traversal, and scheduling tasks.

## Use cases
Use it for matching, expression evaluation, and breadth-first exploration.

## Example problem
Validate whether parentheses are balanced

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
