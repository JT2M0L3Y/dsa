# Merge Intervals

## Pattern description
Sort intervals by start value and merge any overlapping ranges. This is the standard approach for scheduling and range problems.

## Use cases
Use it for calendar scheduling, non-overlap checks, and interval partitioning.

## Example problem
Merge overlapping time intervals

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
