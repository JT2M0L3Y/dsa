# Trie (Prefix Tree)

## Pattern description
Store strings in a tree of characters so that shared prefixes are reused. This makes prefix lookup and insertion efficient.

## Use cases
Use it for autocomplete, prefix lookups, and dictionary operations.

## Example problem
Insert and search words in a dictionary

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
