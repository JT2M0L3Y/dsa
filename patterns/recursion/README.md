# Recursion Fundamentals

## Pattern description
Reduce a problem into smaller instances of itself until a base case is reached. This is the foundation of divide-and-conquer and tree algorithms.

## Use cases
Use it for divide-and-conquer, tree recursion, and backtracking.

## Example problem
Compute factorial iteratively through recursion

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
