# Union Find (Disjoint Sets)

## Pattern description
Maintain parent pointers with path compression and union by rank so that connected components can be merged and queried efficiently.

## Use cases
Use it for connectivity, networks, and incremental grouping.

## Example problem
Group items into connected components

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
