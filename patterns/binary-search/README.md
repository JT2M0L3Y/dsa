# Binary Search Variations

## Pattern description
Binary search works whenever the answer space can be partitioned by a monotonic condition. The pattern extends to rotated arrays, answer optimization, and boundary searches.

## Use cases
Use it for search in sorted data and answer-space reduction.

## Example problem
Find the first true value in a sorted boolean array

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
