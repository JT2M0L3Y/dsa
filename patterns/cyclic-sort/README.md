# Cyclic Sort

## Pattern description
Place each value in its correct index when the numbers are within a known range. This avoids a full sort and supports missing and duplicate number problems.

## Use cases
Use it for array-value placement and missing/duplicate detection.

## Example problem
Find the missing number in the range 0..n

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
