# Heap / Priority Queue

## Pattern description
Keep the smallest or largest values available at the front of a heap, making top-k and scheduled processing efficient.

## Use cases
Use it for top-k selection, scheduling, and merge of sorted streams.

## Example problem
Return the k largest numbers

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
