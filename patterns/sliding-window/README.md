# Sliding Window

## Pattern description
Maintain a moving window of contiguous elements and update a running value as the window expands and shrinks. It removes the need for nested loops in many arrays and strings problems.

## Use cases
Use it for contiguous substrings, maximum/minimum window queries, and prefix-like runs over an array or string.

## Example problem
Maximum subarray sum of fixed size k

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
