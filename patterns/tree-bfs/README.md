# Tree BFS (Level Order)

## Pattern description
Use a queue to visit tree nodes by depth. This is the standard way to process level-by-level information and to find shortest paths in unweighted trees.

## Use cases
Use it when depth matters or when each level needs to be processed together.

## Example problem
Print the tree by levels

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
