# Segment Tree

## Pattern description
Store aggregate data over ranges in a tree structure. It supports efficient range queries and point updates in logarithmic time.

## Use cases
Use it for persistent interval queries and dynamic range aggregations.

## Example problem
Compute range sums with point updates

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
