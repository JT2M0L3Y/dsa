# Bonus advanced algorithms and pattern extensions

This section captures common advanced topics that are not always separate entries in the main 30-pattern list, but appear frequently in interview preparation and problem-solving practice.

## Knapsack and optimization variants

- 0/1 knapsack
- Unbounded knapsack
- Partition equal subset sum
- Target sum
- Count of subsets with a given sum
- DP over weights and values

Related core patterns: [Dynamic Programming (1D)](./dynamic-programming-1d/README.md), [Dynamic Programming (2D)](./dynamic-programming-2d/README.md), [Backtracking](./backtracking/README.md)

## Traveling salesman and bitmask DP

- Held-Karp dynamic programming
- Bitmask shortest path
- TSP variants
- State compression

Related core patterns: [Graph BFS / DFS](./graph-bfs-dfs/README.md), [Shortest Path Algorithms](./shortest-path/README.md), [Bit Manipulation](./bit-manipulation/README.md)

## Advanced graph topics

- Minimum spanning tree (Kruskal / Prim)
- Floyd-Warshall all-pairs shortest path
- Bellman-Ford for negative weights
- Network flow / max flow basics
- Minimum cut

Related core patterns: [Union Find (Disjoint Sets)](./union-find/README.md), [Graph BFS / DFS](./graph-bfs-dfs/README.md), [Shortest Path Algorithms](./shortest-path/README.md)

## Advanced tree and string topics

- AVL / Red-Black Trees
- Segment tree with lazy propagation
- Suffix arrays / suffix automata
- Rolling hash
- Manacher's algorithm

Related core patterns: [Trie (Prefix Tree)](./trie/README.md), [Segment Tree](./segment-tree/README.md), [Hashing / HashMap Patterns](./hashing-hashmap/README.md)

## Practical interview note

The main goal is not to memorize every variant, but to recognize which base pattern a problem is using. Once the core pattern is identified, the advanced variant usually becomes a familiar adaptation.
