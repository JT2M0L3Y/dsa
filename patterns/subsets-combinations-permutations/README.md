# Subsets / Combinations / Permutations

## Pattern description
Explore all choices recursively and backtrack when a partial solution is invalid. This pattern builds all valid combinations or permutations.

## Use cases
Use it for combinatorial enumeration and backtracking search spaces.

## Example problem
Generate all subsets of a set

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
