# Monotonic Stack

## Pattern description
Keep a stack in sorted order and pop until the invariant is restored. This produces linear-time near-neighbor results.

## Use cases
Use it for nearest-greater/nearest-smaller queries and histogram problems.

## Example problem
Find the next greater element for each value

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
