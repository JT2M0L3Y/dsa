# Backtracking

## Pattern description
Build partial solutions and undo the last choice when the next move violates constraints. This is the systematic way to explore possibility spaces.

## Use cases
Use it for constraint satisfaction and combinatorial exploration.

## Example problem
Find all subsets whose sum equals a target

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
