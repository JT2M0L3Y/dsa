# Graph BFS / DFS

## Pattern description
Traverse graphs using BFS for shortest paths on unweighted graphs and DFS to explore connected components or structure.

## Use cases
Use it for connectivity, reachability, and graph traversal.

## Example problem
Count connected components in an undirected graph

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
