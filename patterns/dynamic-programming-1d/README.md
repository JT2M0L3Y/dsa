# Dynamic Programming (1D)

## Pattern description
Compute a value from smaller subproblems and store the result in a one-dimensional table. This is the classic approach for sequences and counts.

## Use cases
Use it for linear state transitions and optimization over a single dimension.

## Example problem
Count the number of ways to climb a staircase

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
