# Topological Sort

## Pattern description
Order nodes in a directed acyclic graph so that each edge points from an earlier node to a later node. In-degree-based processing is the standard method.

## Use cases
Use it for dependency resolution and scheduling DAGs.

## Example problem
Generate a valid study order from course prerequisites

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
