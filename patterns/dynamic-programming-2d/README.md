# Dynamic Programming (2D)

## Pattern description
Define a grid of states, usually over rows and columns or string positions, and build the answer from smaller states.

## Use cases
Use it for grids, string alignment, and knapsack-style problems.

## Example problem
Count the number of unique paths through a grid

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
