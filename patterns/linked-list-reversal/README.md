# In-place Linked List Reversal

## Pattern description
Reverse links in place while saving the next pointer before changing the current node. This preserves O(1) extra memory.

## Use cases
Use it for list reversal, partial list reversal, and rotation problems.

## Example problem
Reverse a singly linked list

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
