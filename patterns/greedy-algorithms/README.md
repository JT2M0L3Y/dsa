# Greedy Algorithms

## Pattern description
Choose the locally best step when the greedy choice property holds. This often produces a globally optimal result with very simple logic.

## Use cases
Use it for scheduling, interval selection, and canonical coin problems.

## Example problem
Select the maximum number of non-overlapping activities

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
