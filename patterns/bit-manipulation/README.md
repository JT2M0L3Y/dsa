# Bit Manipulation

## Pattern description
Use bitwise operators to track values and masks with very low memory overhead. XOR is especially useful for parity and uniqueness problems.

## Use cases
Use it for compact state tracking, bit masks, and XOR tricks.

## Example problem
Find the lone number that appears once

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
