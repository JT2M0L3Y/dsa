# Binary Indexed Tree (Fenwick)

## Pattern description
Store partial sums in a compact tree that supports prefix sums and point updates with low overhead. It is a lighter alternative to a full segment tree.

## Use cases
Use it for dynamic cumulative totals and inversion counting.

## Example problem
Compute prefix sums and update a value

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
