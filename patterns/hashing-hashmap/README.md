# Hashing / HashMap Patterns

## Pattern description
Use a hash map to track counts, membership, and grouped keys in near-constant time. This pattern appears in almost every algorithmic contest.

## Use cases
Use it for frequency counting, lookups, and key grouping.

## Example problem
Count how many times each word appears

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
