# Matrix Traversal

## Pattern description
Traverse a grid with directional movement and visited states. This pattern is used in flood-fill, island counting, and shortest paths in grids.

## Use cases
Use it for grid problems and movement with constraints.

## Example problem
Count the number of islands in a matrix

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
