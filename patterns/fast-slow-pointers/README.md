# Fast & Slow Pointers

## Pattern description
Advance two pointers at different speeds to detect cycles, find middle nodes, or reason about list properties without extra storage.

## Use cases
Use it for cycle detection, midpoint detection, and linked-list optimization.

## Example problem
Detect whether a linked list has a cycle

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
