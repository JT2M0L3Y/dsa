# Tree DFS

## Pattern description
Traverse a tree recursively or with a stack. Preorder, inorder, and postorder all provide different ways to reason about the structure of the tree.

## Use cases
Use it for subtree problems, path-based checks, and tree structure analysis.

## Example problem
Compute the maximum depth of a binary tree

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
