# Two Pointers

## Pattern description
Use two indices to scan the same data structure from different ends or in the same direction. This is especially effective for sorted arrays and linked lists.

## Use cases
Use it for sorted array search, duplicate removal, and palindrome-like checks.

## Example problem
Find a pair that sums to a target in a sorted array

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
