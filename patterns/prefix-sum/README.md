# Prefix Sum

## Pattern description
Precompute cumulative totals to turn a range query into a difference of two prefix values. This is a classic optimization for repeated sum checks.

## Use cases
Use it for frequent range queries and subarray-sum conditions.

## Example problem
Find the sum of a subarray

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
