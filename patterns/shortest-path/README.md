# Shortest Path Algorithms

## Pattern description
Relax edges and keep the best known distance to each node. Dijkstra is the canonical weighted shortest-path algorithm, while Bellman-Ford handles negative weights.

## Use cases
Use it for routing, path planning, and minimum cost traversal.

## Example problem
Find the shortest route from a start node

## Why this pattern matters
Many interview problems are solved by spotting a recurring structure. Once you recognize the pattern, you can apply the same template to multiple questions and avoid solving each one from scratch.
