# Repository guidance

## Agent skills

### Issue tracker

GitHub Issues are used for this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical engineering-skill triage labels are `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo: use the root `GLOSSARY.md` and `docs/adr/` when present, and follow the rules in `docs/agents/domain.md`.
