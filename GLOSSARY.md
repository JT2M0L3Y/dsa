# DSA Interview Guide

This repository organizes interview-preparation material around reusable problem-solving approaches and the data structures and algorithms that support them.

## Language

**DSA pattern**:
A reusable problem-solving strategy for a class of data-structure-and-algorithm interview problems. It describes an approach to recognize and apply, not a specific data structure or a single algorithm.
_Avoid_: Algorithm (when referring to a problem-solving strategy)
